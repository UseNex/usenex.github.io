# Nex Game Platform - Complete Documentation

## Getting Started

### What is Nex?

Nex is a lightweight HTML5 game platform that lets you embed and play web games with minimal setup. Version 2.0 introduces a flexible loading screen system with both built-in and custom loader options.

#### Quick Start

Add the Nex script to your HTML using the latest commit hash:

```html
<script src="https://cdn.jsdelivr.net/gh/UseNex/nex-js@78fe8819c6460911bb87b050862b30bc10d43e0a/nex.min.js"></script>
```

Then use the `<nex-game>` element:

```html
<!-- Built-in loader (white ring + blur background) -->
<nex-game alias="2048" gid="my-game-1"></nex-game>

<!-- Custom loader mode (no built-in loader) -->
<nex-game alias="granny" gid="my-game-2" loading-screen="true"></nex-game>
```

That's it! The game will automatically load and be ready to play.

## Component API

### HTML Attributes

| Attribute | Type | Required | Description |
|-----------|------|----------|-------------|
| `alias` | string | Yes | Game identifier (e.g., "fnaf", "2048") |
| `gid` | string | Yes | Unique session ID for your game instance |
| `loading-screen` | string | No | `"true"` = custom loader mode, `"false"` = built-in loader (default) |

#### Loading Screen Modes

**Built-in Loader (Default)**
Shows a beautiful white ring with blur background, percentage counter, and game title.

```html
<nex-game alias="2048" gid="game-1"></nex-game>
<!-- or explicitly -->
<nex-game alias="2048" gid="game-1" loading-screen="false"></nex-game>
```

**Custom Loader Mode**
No built-in loader is shown. You must provide your own loading UI using the progress events.

```html
<nex-game alias="granny" gid="game-2" loading-screen="true"></nex-game>
```

#### Example

```html
<!-- With built-in loader -->
<nex-game alias="fnaf" gid="game-123"></nex-game>

<!-- With custom loader mode and styling -->
<nex-game 
  alias="2048" 
  gid="puzzle-game"
  loading-screen="true"
  style="width:800px;height:600px;"
></nex-game>
```

### JavaScript API (window.nex)

#### Methods

**on(eventName, callback)** - Listen to game lifecycle events
```js
window.nex["my-game"].on("ready", () => console.log("Game loaded!"))
```

**start()** - Start the game manually (required in both modes)
```js
window.nex["my-game"].start()
```

#### Events

| Event | When it fires | Mode |
|-------|---------------|------|
| `progress` | During loading (0-100%) | Custom mode only |
| `ready` | Game is fully loaded | Both modes |
| `error` | Something went wrong | Both modes |

#### Complete Example (Custom Loader)

```js
const gid = "my-game"

window.nex[gid].on("progress", (data) => {
  console.log(`Loading: ${data.progress}%`)
  // Update your custom loader UI here
})

window.nex[gid].on("ready", () => {
  console.log("Ready to play!")
  // Hide your custom loader
  document.getElementById('loader').style.display = 'none'
  window.nex[gid].start() // Required!
})

window.nex[gid].on("error", (err) => {
  console.error("Error:", err.message)
})
```

## Metadata API

### Available Methods

**window.nex.metadata.getAllAliases()**
```js
const games = window.nex.metadata.getAllAliases()
// ['2048', 'fnaf', 'slope', ...]
```

**window.nex.metadata.get(alias)**
```js
const game = window.nex.metadata.get("2048")
console.log(game.name, game.category)
```

**window.nex.metadata.getAllMetadata()**
```js
const allGames = window.nex.metadata.getAllMetadata()
```

**window.nex.metadata.alias[alias]**
```js
const game = window.nex.metadata.alias["fnaf"]
console.log(game.name) // "Five Nights at Freddy's"
```

### Game Metadata Structure

```ts
interface GameMetadata {
  alias: string        // Unique identifier
  name: string         // Display name
  category: string     // Game genre/category
  description: string  // Short description
  img: string          // Thumbnail URL (400x300px WebP)
}
```

## Examples

### Basic Usage (Built-in Loader)

```html
<!DOCTYPE html>
<html>
<head>
  <script src="https://cdn.jsdelivr.net/gh/UseNex/nex-js@78fe8819c6460911bb87b050862b30bc10d43e0a/nex.min.js"></script>
  <style>body{margin:0;background:#000}nex-game{display:block;width:100vw;height:100vh}</style>

<body>
  <!-- Uses built-in loader by default -->
  <nex-game alias="slope" gid="game-1"></nex-game>
  <script>
    const gid="game-1"
    window.nex[gid].on("progress",(data)=>console.log(`Loading: ${data.progress}%`))
    window.nex[gid].on("ready",()=>{console.log("Game ready!");window.nex[gid].start()})
    window.nex[gid].on("error",(err)=>console.error("Game error:",err.message))
  </script>
</body>
</html>
```

## Loading Screen Guide

### Loader Modes

Nex 2.0 introduces two loading screen modes to give you full control over the user experience.

#### Built-in Loader (Default)

When `loading-screen` is not set or set to `"false"`, Nex shows its elegant built-in loader.

**Features:**
- White circular progress ring
- Blurred game thumbnail background
- Percentage counter (0% - 100%)
- Game title display
- Smooth fade-out transition
- Error message display

```html
<nex-game alias="granny" gid="game-1"></nex-game>
```

#### Custom Loader Mode

When `loading-screen="true"`, Nex does NOT show any built-in loader. You must provide your own loading UI.

**Features:**
- No built-in UI elements
- Full control over loading visuals
- Progress events (0-100%)
- Ready event to hide loader
- Error event for failure handling

```html
<nex-game alias="granny" gid="game-1" loading-screen="true"></nex-game>
```

#### Event Flow Comparison

| Event | Built-in Mode | Custom Mode |
|-------|---------------|-------------|
| `progress` | Fires (optional) | Fires (required for UI) |
| `ready` | Fires, auto-starts | Fires, you must call `start()` |
| `error` | Shows in loader | You handle in UI |

## Best Practices

### Performance Tips

**1. Use Unique GIDs**
```html
<!-- Good -->
<nex-game alias="2048" gid="game-${Date.now()}"></nex-game>
<!-- Bad -->
<nex-game alias="2048" gid="game-1"></nex-game>
```

**2. Lazy Load Games**
```js
function loadGame(alias){const c=document.createElement('nex-game');c.setAttribute('alias',alias);c.setAttribute('gid',`game-${Date.now()}`);document.body.appendChild(c)}
```

**3. Handle Errors Gracefully**
```js
window.nex[gid].on('error',(err)=>{document.querySelector('.error').textContent='Failed to load game'})
```

**4. Clean Up on Unmount**
```js
function removeGame(){const game=document.querySelector('nex-game');if(game)game.remove()}
```

**5. Choose the Right Loader Mode**

| Use Case | Recommended Mode |
|----------|------------------|
| Quick embed, no customization | Built-in loader (default) |
| Branded loading experience | Custom loader (`loading-screen="true"`) |
| Minimalist design | Custom loader |
| Rapid prototyping | Built-in loader |

**6. Thumbnail Display**
```css
.game-thumbnail{width:100%;aspect-ratio:4/3;object-fit:cover}
```

**7. Cache for Faster Loading**
After the first load, games are cached by the browser for faster subsequent loads.

```js
// Warm up the cache by preloading a game
setTimeout(()=>{const p=document.createElement('nex-game');p.setAttribute('alias','2048');p.setAttribute('gid','preload');p.style.display='none';document.body.appendChild(p)},1000)
```

### Common Issues & Solutions

**Game doesn't load**
```js
const valid=window.nex.metadata.getAllAliases();console.log('Available games:',valid)
```

**Duplicate GID error**
```js
const gid=`game-${Date.now()}-${Math.random().toString(36).substr(2,6)}`
```

**Game won't start**
```js
window.nex[gid].on('ready',()=>{window.nex[gid].start()})
```

**Built-in loader not showing**
```html
<!-- Built-in loader shows -->
<nex-game alias="2048" gid="game-1"></nex-game>
<!-- No built-in loader -->
<nex-game alias="2048" gid="game-1" loading-screen="true"></nex-game>
```

**Custom loader not receiving progress events**
```js
window.nex[gid].on('progress',(data)=>{console.log(data.progress)}) // Requires loading-screen="true"
```

**Thumbnails not loading**
```js
const game=window.nex.metadata.get('2048');if(game){console.log('Thumbnail URL:',game.img)}
```

**CORS issues** - Serve your page through a local server instead of opening the file directly.

**Game loads but screen is blank**
```js
window.nex[gid].on('ready',()=>{window.nex[gid].start()}) // Required in both modes!
```
