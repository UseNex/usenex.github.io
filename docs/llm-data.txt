# NexGame Component - Complete Documentation

## Overview

NexGame is a lightweight, performance-optimized custom HTML5 element (`<nex-game>`) designed to fetch, cache, and securely execute web games from CDN.

### Key Features
- Race-fetch strategy across multiple CDN nodes
- Cache Storage API caching (minimizes data usage)
- Isolated sandbox iframe execution
- Self-healing runtime with hot-reload capabilities

### Installation
```html
<script src="https://cdn.jsdelivr.net/gh/UseNex/nex-js@34b490a8957a17554793edcdd153aabb42a75268/nex.min.js"></script>
```

---

## Component Attributes

The `<nex-game>` element supports the following attributes:

| Attribute | Type | Required | Description |
|-----------|------|----------|-------------|
| `alias` | string | Yes | Unique game identifier (e.g., "fnaf", "angry-birds") |
| `gid` | string | Yes | Unique session ID for event mapping and instance deduplication |

### Example
```html
<nex-game alias="fnaf" gid="session-123"></nex-game>
```

## Metadata API (`window.nex.metadata`)

The Metadata API lets you discover and access game information without loading the actual game.

### Available Methods

#### `window.nex.metadata.getAllAliases()`
Get a list of all game identifiers.

```js
const games = window.nex.metadata.getAllAliases()
console.log(games) // ['2048', 'fnaf', 'slope', ...]
```

#### `window.nex.metadata.get(alias)`
Get metadata for a specific game.

```js
const game = window.nex.metadata.get("2048")
console.log(game.name) // "2048"
console.log(game.category) // "Puzzle"
```

#### `window.nex.metadata.getAllMetadata()`
Get metadata for all games at once.

```js
const allGames = window.nex.metadata.getAllMetadata()
// Returns object with all game metadata
```

#### `window.nex.metadata.alias[alias]`
Shortcut to access game metadata.

```js
const game = window.nex.metadata.alias["fnaf"]
console.log(game.name) // "Five Nights at Freddy's"
```

### Game Metadata Structure

Each game in the Nex platform has the following structure:

```ts
interface GameMetadata {

  name: string         // Display name
  category: string     // Game genre/category
```

## Global API (`window.nex`)

The component exposes a reactive registry proxy at `window.nex[gid]`.

### Methods

#### `on(eventName, callback)`
Registers an event listener for a specific lifecycle phase. Can be declared before the DOM element exists.

**Parameters:**
- `eventName`: `"progress"` | `"ready"` | `"error"`
- `callback`: `(data: Object) => void`

**Example:**
```js
window.nex["session-123"].on("ready", () => {
  console.log("Game is ready!")
})
```

#### `start()`
Triggers execution and rendering of the game. If assets are still downloading, execution waits for `"ready"` event.

**Example:**
```js
window.nex["session-123"].start()
```

---

## Lifecycle Events

### `progress` Event

Fired continuously during manifest lookup and chunk downloads.

**Payload:**
```ts
{ progress: number }  // 0-100, already a percentage
```

**Example:**
```js
nex.on("progress", (data) => {
  console.log(`Loading: ${data.progress}%`)
})
```

---

### `ready` Event

Fired when the entire HTML payload is fetched, validated, merged, and cached. Game is ready to start.

**Payload:** `void`

**Example:**
```js
nex.on("ready", () => {
  console.log("Game is ready!")
  nex.start()
})
```

---

### `error` Event

Fired on network failure, validator rejection, or alias not found.

**Payload:**
```ts
{ message: string }
```

**Example:**
```js
nex.on("error", (err) => {
  console.error("Game loading failed:", err.message)
})
```

## Technical Architecture

### Race Fetch Strategy

Queries all CDN endpoints simultaneously. The fastest successful response wins; slower requests are aborted via `AbortController`.

**Benefits:**
- Minimizes latency
- Improves reliability across geographic regions
- Automatic failover

**Implementation:**
```js
const endpoints = [
  "https://gcore.jsdelivr.net/gh/UseNex/g-assets-enc/",
  "https://testingcf.jsdelivr.net/gh/UseNex/g-assets-enc/",
  "https://cdn.jsdelivr.net/gh/UseNex/g-assets-enc/"
]

const controllers = []
const promises = endpoints.map((url) => {
  const controller = new AbortController()
  controllers.push(controller)
  return fetch(url + "game_data.json", { signal: controller.signal })
})
const response = await Promise.any(promises)
controllers.forEach(c => c.abort())
```

---

### Cache-First Strategy

All requests check Cache Storage before hitting the network, eliminating repetitive data usage on mobile/4G networks.

**Benefits:**
- Reduces bandwidth usage
- Faster subsequent loads
- Works offline after first load

**Cache Details:**
- Cache name: `np-cache-1`
- TTL: 24 hours (86400000ms)

**Implementation:**
```js
const cache = await caches.open('np-cache-1')
const cached = await cache.match(request)
if (cached) return cached
const response = await fetch(request)
cache.put(request, response.clone())
return response
```

---

### Self-Healing Runtime

Listens to live attribute changes (`alias`, `gid`) via `attributeChangedCallback`, gracefully terminating active streams, clearing event registries, and hot-reloading new game pipelines without layout shifts.

**Supported mutations:**
- `alias` change → reloads new game
- `gid` change → creates new instance context

**Benefits:**
- No page refresh required
- State cleanup prevents memory leaks
- Smooth transitions between games

---

### Sandbox Iframe

Injects games into an isolated Shadow DOM container with maximized permissions.

**Enabled Features:**
- Pointer lock
- Local storage
- Audio autoplay
- Gamepad API
- Clipboard write
- Fullscreen
- Downloads
- Modals

**Implementation:**
```html
<iframe
  sandbox="allow-scripts allow-same-origin allow-forms allow-modals allow-popups allow-pointer-lock allow-downloads allow-presentation allow-top-navigation-by-user-activation"
  allow="autoplay; fullscreen; gamepad; pointer-lock; xr-spatial-tracking; clipboard-write"
>
</iframe>
```

## Examples

### Basic Usage

Complete example of loading and starting a game.

**HTML:**
```html
<!DOCTYPE html>
<html>
<head>
  <script src="https://cdn.jsdelivr.net/gh/UseNex/nex-js@34b490a8957a17554793edcdd153aabb42a75268/nex.min.js"></script>
</head>
<body>
  <nex-game alias="fnaf" gid="my-game-1"></nex-game>

  <script>
    const gid = "my-game-1"
    
    window.nex[gid].on("progress", (data) => {
      console.log(`Loading: ${data.progress}%`)
    })

    window.nex[gid].on("ready", () => {
      console.log("Game ready!")
      window.nex[gid].start()
    })

    window.nex[gid].on("error", (err) => {
      console.error("Game error:", err.message)
    })
  </script>
</body>
</html>
```

### Game Gallery

Create a game selection screen with thumbnails.

**HTML:**
```html
<!DOCTYPE html>
<html>
<head>
  <script src="https://cdn.jsdelivr.net/gh/UseNex/nex-js@34b490a8957a17554793edcdd153aabb42a75268/nex.min.js"></script>
  <style>
    * { margin: 0; padding: 0; box-sizing: border-box; }
    body { 
      font-family: system-ui;
      background: #0a0a0f;
      color: #fff;
      padding: 20px;
    }
    .grid {
      display: grid;
      grid-template-columns: repeat(auto-fill, minmax(200px, 1fr));
      gap: 20px;
      max-width: 1200px;
      margin: 0 auto;
    }
    .card {
      background: #1a1a2e;
      border-radius: 12px;
      padding: 20px;
      text-align: center;
      cursor: pointer;
      transition: transform 0.2s;
    }
    .card:hover { transform: translateY(-5px); }
    .card img {
      width: 100%;
      aspect-ratio: 4/3;
      object-fit: cover;
      border-radius: 8px;
      margin-bottom: 10px;
    }
    .card h3 { font-size: 1rem; margin-bottom: 5px; }
    .card p { font-size: 0.8rem; color: #888; }
  </style>
</head>
<body>
  <div class="grid" id="gallery"></div>
  <nex-game id="game-container" style="display:none;"></nex-game>

  <script>
    const games = window.nex.metadata.getAllMetadata()
    const gallery = document.getElementById('gallery')

    Object.values(games).forEach(game => {
      const card = document.createElement('div')
      card.className = 'card'
      card.innerHTML = `
        <img src="${game.img}" alt="${game.name}" loading="lazy">
        <h3>${game.name}</h3>
        <p>${game.category}</p>
      `
      card.onclick = () => playGame(game.alias)
      gallery.appendChild(card)
    })

    function playGame(alias) {
      const container = document.getElementById('game-container')
      container.style.display = 'block'
      container.setAttribute('alias', alias)
      container.setAttribute('gid', 'gallery-game')
      
      window.nex['gallery-game'].on('ready', () => {
        window.nex['gallery-game'].start()
      })
    }
  </script>
</body>
</html>
```

2. `https://testingcf.jsdelivr.net/gh/UseNex/g-assets-enc/`
3. `https://quantil.jsdelivr.net/gh/UseNex/g-assets-enc/`
4. `https://fastly.jsdelivr.net/gh/UseNex/g-assets-enc/`
5. `https://jsdelivr.b-cdn.net/gh/UseNex/g-assets-enc/`
6. `https://cdn.jsdelivr.net/gh/UseNex/g-assets-enc/`

All nodes serve the same encrypted game assets.

---

## Architecture Flow

1. **User includes** `<nex-game>` element with `alias` and `gid`
2. **Component initializes** and checks for existing instance with same `gid`
3. **Fetches** `game_data.json` from CDN using race strategy
4. **Validates** alias exists in game data
5. **Fetches** `nr.txt` to get chunk count
6. **Downloads** encrypted chunks (`src.part1.txt`, `src.part2.txt`, etc.)
7. **Decrypts** each chunk using XOR cipher
8. **Assembles** full HTML payload
9. **Emits** `ready` event
10. **Starts** game when `start()` called
11. **Executes** in isolated sandbox iframe

## Best Practices

### 1. Use Unique GIDs
Always use unique `gid` values for each game instance to prevent conflicts.

```html
<!-- Good -->
<nex-game alias="2048" gid="game-${Date.now()}"></nex-game>

<!-- Bad - reusing same gid -->
<nex-game alias="2048" gid="game-1"></nex-game>
```

### 2. Lazy Load Games
Only create game elements when needed.

```js
function loadGame(alias) {
  const container = document.createElement('nex-game')
  container.setAttribute('alias', alias)
  container.setAttribute('gid', `game-${Date.now()}`)
  document.body.appendChild(container)
}
```

### 3. Handle Errors Gracefully
Always listen for error events.

```js
window.nex[gid].on('error', (err) => {
  document.querySelector('.error').textContent = 'Failed to load game'
})
```

### 4. Clean Up on Unmount
Remove game elements when no longer needed.

```js
function removeGame() {
  const game = document.querySelector('nex-game')
  if (game) game.remove()
}
```

### 5. Thumbnail Display
When displaying game thumbnails, use 4:3 aspect ratio for optimal display:

```css
.game-thumbnail {
  width: 100%;
  aspect-ratio: 4/3;
  object-fit: cover;
}
```

## Common Issues & Solutions

### Game doesn't load

**Solution:** Check that you're using a valid alias.

```js
const valid = window.nex.metadata.getAllAliases()
console.log('Available games:', valid)
```

### Duplicate GID error

**Solution:** Use unique GIDs for each instance.

```js
const gid = `game-${Date.now()}-${Math.random().toString(36).substr(2, 6)}`
```

### Game won't start

**Solution:** Make sure to call `start()` after the `ready` event.

```js
window.nex[gid].on('ready', () => {
  window.nex[gid].start()
})
```

### Thumbnails not loading

**Solution:** Check if the game exists and the CDN is accessible. Thumbnails are 400x300px WebP images with 4:3 aspect ratio.

```js
const game = window.nex.metadata.get('2048')
if (game) {
  console.log('Thumbnail URL:', game.img)
}
```

### CORS issues

**Solution:** The Nex CDN endpoints are configured for cross-origin requests. If you're developing locally, serve your page through a local server instead of opening the file directly.
