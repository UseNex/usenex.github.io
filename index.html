Nex.js

Seamless game embedding for modern web applications. Fast, secure, and reactive.

Get Started View Documentation

Built for performance & control.

Everything your application needs to handle embedded games seamlessly.

Race-Fetch CDN

Flashes queries across multiple CDN nodes simultaneously. The fastest successful response wins, aborting slower requests.

Aggressive Caching

Leverages native Cache Storage API (np-cache-1) to drastically minimize data usage on subsequent loads.

Isolated Sandboxing

Executes games safely inside an unconstrained shadow DOM iframe with full audio, gamepad, and pointer-lock support.

Effortless integration.

See how simple it is to add games to your web app.

Example Implementation HTML / JS 
<!-- Drop the custom element -->
<nex-game alias="crossy-road" gid="game-1"></nex-game>

<!-- Control via reactive API -->
<script>
  window.nex["game-1"].on("ready", () => {
    window.nex["game-1"].start();
  });
</script>
